# evidence/

Real artifacts produced on the hardware **only**: build logs, boot logs, DIAG
dumps, test logs, screenshots and the demo-video link. Nothing in this folder is
written by hand or by the agent. Reports and tables are generated *from* these
files by the scripts in `tools/` and `ml/`.

Naming: `m<milestone>_<topic>.<ext>`, e.g. `m1_boot.log`, `m1_build.txt`,
`m2_imu.log`, `m5_parity.log`, `t4_soak.log`.
