# data/

Anonymized raw sensor captures from the RT-Spark (`raw/<session_id>.csv`) and
`manifest.csv`. The capture protocol, CSV schema and labeling cheat sheet are
added in **M3** (PRD §7.1).

Rules: operator codes only (P1, P2, …), never names. Files containing anything
private use the `*_private*` suffix, which is git-ignored.
